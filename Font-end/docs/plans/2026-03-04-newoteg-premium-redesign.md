# Design Document - NEWOTEG Premium Redesign

## Overview
This design aims to transform the current interface into a "Premium Dark Tech" experience. The focus is on high-contrast visuals, smooth animations, and a sophisticated color palette that emphasizes the "Electronic Component" nature of the brand.

## Key Changes

### 1. Branding
- Brand name updated to **NEWOTEG** (all caps) across all components.
- Modern, wide-tracking typography for the logo.

### 2. Visual Identity (Premium Dark Tech)
- **Primary Color**: Vancian Blue (#00f2ff) or deep Electric Cobalt (#2d5cf7) - high vibrance against dark backgrounds.
- **Backgrounds**: Deep Obsidian (#0a0a0b) with layered glassmorphism (blurs, thin borders).
- **Typography**: Switching to a more modern sans-serif (e.g., 'Syne' or 'Outfit') for headings, keeping 'Inter' for body text.

### 3. Component Overhaul
#### Header
- Full glassmorphism effect.
- Animated underline for navigation items.
- SearchBar with an "expand on click" animation for a cleaner look.

#### HeroBanner
- Dynamic background: Adding a subtle animated grid or particles effect (mimicking circuits).
- Bold, capitalized titles.
- High-vibrance CTA buttons with "glow" on hover.

#### CategoryGrid
- Card aesthetics: Darker base with thin, glowing borders on hover.
- Lucide icons with custom gradients.

### 4. Interactions
- Smooth scrolling.
- Staggered entry animations for cards.
- Enhanced haptic-style transitions.

## Approved Approach
The user approved the "Launch", and the design will prioritize the **Ultra Dark Tech** aesthetic as it offers the most "WOW" factor for an electronics supplier.
