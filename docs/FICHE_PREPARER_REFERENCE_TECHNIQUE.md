## 2. Les preuves disponibles

| Élément | Observation ou document | Ce qui reste inconnu |
|---|---|---|
| Marquage | Photo nette des lignes et du logo | |
| Boîtier / connecteur | Vue de face et de côté, nombre de connexions | |
| Encombrement | Dimensions et unités réellement relevées, entraxe ou pas | |
| Fonction du montage | Schéma ou documentation de l'appareil, si disponible | |
| Notice fabricant | Fabricant, référence exacte, URL, page et révision | |
| Conditions d'emploi | Contraintes connues de l'application, avec leur source | |

Une donnée non établie reste « inconnue ». Ne pas convertir une ressemblance, un nom de série ou une valeur maximale en preuve de compatibilité. Cette préparation ne demande pas de mesure sous tension ni d'ouverture d'un appareil présentant un risque.

## 3. Questions à poser

1. Le document concerne-t-il exactement le fabricant, la référence, le suffixe et le boîtier observés ?
2. Quelles données manquent pour examiner ce besoin dans son application précise ?
3. Les dimensions, le brochage ou le câblage sont-ils établis pour les deux éléments comparés ?
4. Les limites et conditions techniques nécessaires sont-elles documentées, ou seulement supposées ?
5. Une revue ou un essai par une personne compétente est-il nécessaire avant toute décision ?
